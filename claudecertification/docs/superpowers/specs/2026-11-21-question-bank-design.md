# Claude Certification Question Bank — 통합 설계

날짜: 2026-11-21 · 대상: `output/CCTOTALQA/question_bank.html`

## 목표
`output/` 아래 모든 시험의 문제 데이터를 `question_bank.html` 하나에서 풀고 볼 수 있게 한다.
현재 페이지는 CCDV-F 하나만 담은 단일 목록이다.

## 범위
- 포함: 시험 탭 UI, 통합 데이터 빌드, 언어 표시 규칙, 번역 대기 표시.
- 제외(나중): 한국어/영어 번역 작업 자체(별도 배치), 시험 간 중복 제거.

## 데이터 소스 (총 1,911문제)
시험마다 `output/<시험>/` 아래 3단계: `00_bronze`(생데이터) · `10_silver`(전처리 중) · `20_gold`(페이지에 올라가는 데이터, `all.json` 하나).
페이지는 각 시험의 `20_gold/all.json`(페이지 레코드 형식)만 읽는다.

| 시험 | 문제 수 | silver / bronze 원천 |
|---|---|---|
| CCAO-F | 226 | silver: `all.json` + `all_ko.md`(한국어) |
| CCAR-F | 606 | silver: `all.json`(170) · bronze: `CCAR-Udemy01~06.json`(360, 일본어), `MyPractice.json`(76) |
| CCAR-P | 819 | silver: `all.json` |
| CCDV-F | 260 | silver: `udemy_ja.json`(한국어 154 + 일본어 106), `all.json`(영어) · bronze: `udemy_en.json`, `udemy2_ja.json` |

## 메뉴 구성
1. 맨 위 시험 탭: `전체 · CCAO-F · CCAR-F · CCAR-P · CCDV-F`, 탭마다 문제 수.
2. 필터 (선택한 탭 기준으로 바뀐다):
   - 분야: 그 시험의 분야만, 문제 수 표시 (현재 선택한 언어 그룹 기준 개수). 분야 정보가 없는 문제는 `미분류`.
   - 출처: 그 시험에 있는 출처만 (예: CCAR-F → `Udemy`, GitHub 저장소 3곳).
   - 언어: `한국어 + 영어` / `일본어 + 영어` 두 가지뿐 (아래 규칙).
   - 상태(전체·미풀이·오답·정답), 키워드 검색.
3. `전체` 탭에서는 분야 필터를 비활성 (시험마다 분야가 달라서).
4. 통계(전체·푼 문제·정답·오답·진행 막대)는 현재 탭 기준. `기록 초기화`는 현재 탭 문제만 지운다.
5. 섞기 / 원래 순서 버튼은 유지.

## 언어 규칙
- 모든 문제는 `origin`(원문 언어)을 가진다: GitHub 저장소 출처 = `en`, Udemy = `ja`.
- 언어 드롭다운이 고르는 것은 원문 언어 그룹이다.
  - `한국어 + 영어` → `origin = en` 문제 (한국어 번역 + 영어 원문)
  - `일본어 + 영어` → `origin = ja` 문제 (일본어 원문 + 영어 번역)
  - 그래서 일본어 Udemy 문제는 `일본어 + 영어`를 골라야 보인다.
- 해설은 항상 한국어.
- 번역이 아직 없는 항목: 원문을 보여주고 `번역 대기` 태그를 붙인다.
  - 한국어 번역 없음 → 영어 원문 + `한국어 번역 대기`
  - 영어 번역 없음(일본어 문제) → 일본어만 + `영어 번역 대기`
  - 한국어 해설 없음 → 원문 해설 + `해설 번역 대기`

## 데이터 모델 (문제 1건)
`id`, `exam`, `domain`, `source`, `origin`(`en`|`ja`), `select_count`, `answer`,
`q`/`ch`/`ex`: 화면 기본 언어 본문(한국어 번역이 있으면 한국어, 없으면 원문),
`en`: `{q, ch}` 영어 병기용(있을 때만), `px`: 해설이 한국어가 아님, `pq`: 문제·보기가 한국어가 아님(영어 원문 문제만),
`ce`: 보기별 해설, `ref`: 참고 링크 (Udemy, 있을 때만).

## 빌드
- `work/scripts/build_bank.py gold`가 silver+bronze로 각 시험의 gold를 만들고, 인자 없이 실행하면 gold만 읽어 `bank_head.html` + `bank_body.html` 템플릿에 데이터를 내장한 `question_bank.html` 한 파일을 다시 만든다. 더블클릭으로 열리는 방식(file://) 유지.
- 번역 병합은 아직 없다. 번역 파일이 생기면 `rec()` 호출 전에 id 기준으로 ko/en 을 채우는 코드를 추가한다(그때까지는 원문 + 번역 대기 태그).

## 풀이 기록
- 브라우저 localStorage, `id` 기준. 기존 CCDV-F 기록은 `id`가 그대로여서 유지된다.
- 키는 기존 CCDV-F 키를 그대로 이어 쓴다.

## 검증
- 빌드 후 탭별 문제 수가 위 표와 같은지 확인 (1,911).
- 탭 전환 시 분야·출처·언어 목록이 그 시험 것만 나오는지, 번역 대기 태그가 붙는지 확인.

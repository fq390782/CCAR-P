# 문체 가이드: 표 중심 (B) · 근거는 소절 끝에

목표: 구조적, 간결, 직관적인 문서. 사용자가 고른 기준 샘플은 아래 "기준 샘플"이다.

## 기준 샘플 (사용자가 고른 형태)

변환 전:
```
**Coordinator → Subagent로 넘길 것 / 넘어가지 않는 것**
- 넘길 것: 위임 prompt 안에 subtask에 필요한 컨텍스트(file path, 판단 근거, 이전 결정 등)를 **명시적으로** 적는다. ... [Udemy-0004] [Amey-0025]
- 자동으로 넘어가지 않는 것: 부모의 대화 이력, tool 결과, 부모의 system prompt. ... [Udemy-0004]
...
```

변환 후:
```
**Coordinator → Subagent 전달 범위**

| 구분 | 내용 |
|---|---|
| 넘길 것 | 위임 prompt 속 컨텍스트 명시<br>(file path, 판단 근거, 이전 결정) |
| 안 넘어감 | 부모 이력, tool 결과, system prompt<br>(fork형만 예외) |
| 공통 방침 | subagent 정의 / `CLAUDE.md`에 기재 |
| 품질 저하 | 원인 = handoff 컨텍스트 누락<br>→ 큰 모델·subagent 추가로 해결 ✗ |

<sub>근거: Amey-0025, Udemy-0004</sub>
```

## 규칙 R1~R12 (모두 지킨다)

### 구조
- **R1. 표가 기본 단위다.** 같은 형태의 항목이 2개 이상이면 표로 만든다.
  - 해당하는 경우: 구분/내용, 옵션 비교, 상황 → 정답, 이름 → 의미, 정답 vs 오답, 증상 → 원인 → 조치.
  - 열 이름은 짧은 명사로 쓴다(구분, 내용, 상황, 정답, 오답, 이유, 의미 등).
  - 한 표는 2~4열이다. 5열 이상이면 표를 나눈다.
- **R2. 표가 안 맞는 경우만 목록을 쓴다.**
  - 순서가 핵심인 절차는 번호 목록 `1.`로 쓴다.
  - 서로 형태가 다른 단발성 사실 1~2개는 bullet로 쓴다.
  - 문단(줄글)은 금지한다.
- **R3. 소절(###)은 이 순서로 쓴다.**
  1. 소제목 바로 아래 **핵심 한 줄**(bold, 30자 내외)
  2. 표 또는 목록
  3. 그림 줄
  4. 근거 줄
  - 핵심 한 줄은 그 소절 전체를 요약하는 결론이다(예: `**금지는 prompt가 아니라 권한으로 강제**`).

### 문장
- **R4. 개조식으로 쓴다.**
  - 명사형이나 체언으로 끝낸다(예: "~ 명시", "~ 금지", "~ 필요", "오답").
  - "~다.", "~한다.", "~이다." 같은 서술 종결은 금지한다.
  - 마침표는 찍지 않는다.
- **R5. 한 칸(셀)이나 한 bullet에는 주장 하나만 쓴다.**
  - 한 줄은 40자 이내로 쓴다. 넘으면 셀 안에서 `<br>`로 줄을 나누되, 셀 하나당 최대 3줄이다.
- **R6. 기호를 고정해서 쓴다.**
  - `→` 결과·인과·다음 단계
  - `✗` 오답·금지·효과 없음
  - `✓` 정답·권장(표에 정답/오답이 섞일 때만)
  - `=` 정의·동치
  - `·` 나열
  - `⚠️` 공식 문서와 어긋나거나 시점에 따라 바뀌는 내용(기존 ⚠️ 전용, 새로 만들지 않음)
- **R7. 군더더기를 삭제한다.**
  - 접속사·부사: 또한, 즉, 따라서, 그래서, 다만, 게다가, 참고로, 매우, 반드시, 사실상
  - 반복되는 주어("이것은", "이 방식은")
- **R8. 용어 표기는 그대로 둔다.** 영어 용어, 코드, 파라미터, 상태 코드는 원문과 백틱 표기를 유지한다. bold는 핵심 한 줄과 표 안의 진짜 키워드에만 쓴다(셀마다 bold 금지).

### 근거 id
- **R9. 근거 id는 소절 끝에 모은다.**
  - 본문, 표, 목록 안의 `[Amey-0004]` 같은 인라인 id는 모두 제거한다.
  - 각 소절 맨 끝에 `<sub>근거: id1, id2, ...</sub>` 한 줄로 모은다. 중복은 없애고 정렬한다.
  - 소절이 없는 장(2~5장)은 장 끝에 모은다. 2장 표의 "근거" 열은 삭제하고 표 아래 근거 줄로 옮긴다.
  - **원본에 있던 id는 하나도 빠지면 안 된다.**

### 보존 (절대 규칙)
- **R10. 사실을 보존한다.**
  - 원본의 모든 사실, 수치, 파라미터, 조건, 예외, 오답 이유를 남긴다.
  - 압축은 표현만 줄이는 것이다. 정보를 줄이는 것이 아니다.
  - 새 사실을 추가하지 않는다.
  - ⚠️ 항목은 이유까지 포함해 그대로 남긴다(표현만 압축).
- **R11. 그림 줄을 보존한다.**
  - `![...](svg/...)` 줄과 바로 아래 `*그림: ...*` 줄은 글자 하나 바꾸지 않는다.
  - 순서를 바꾸지 않고, 원래 소절 안(근거 줄 바로 위)에 둔다.
- **R12. 골격을 보존한다.**
  - 제목 `# ...`과 바로 아래 `> 시험 비중 ...` 줄은 그대로 둔다.
  - `## 1.`~`## 5.` 다섯 장과 그 순서를 유지한다.
  - `###` 소제목은 번호를 유지하고, 문구만 짧게 다듬을 수 있다.
  - 5장 체크리스트는 `- [ ]` 목록으로 유지하되 R4·R5를 적용한다.

<h3 id="bank-mocks-h114">M2-Q43 (V2-D5.1), Select TWO</h3>

<p id="sec-bank-mocks-p513" data-kind="prose"><strong>Scenario.</strong> A document agent processes uploads from the internet.</p>

<p id="sec-bank-mocks-p514" data-kind="prose"><strong>Question.</strong> Which TWO controls fit? Select TWO.</p>

<p id="sec-bank-mocks-p515" data-kind="prose"><strong>Options.</strong>
A) Input screening: scan uploads for malicious content before the
model reads them.
B) Sandboxing: process uploads isolated from secrets and the network.
C) A friendly system prompt.
D) Auto-forwarding uploads to all staff.
E) Disabling all logging.</p>

<p id="sec-bank-mocks-p516" data-kind="prose"><strong>Answer.</strong> A, B</p>

<p id="sec-bank-mocks-p517" data-kind="prose"><strong>Key.</strong> A, B. Decisive phrase: &quot;uploads from the internet.&quot; Why:
untrusted uploads need screening before model exposure and sandboxing
before execution. C is guidance. D spreads the risk. E blinds the
team.</p>

<p id="sec-bank-mocks-p518" data-kind="prose">Counterfactual: none.</p>


<h3 id="bank-mocks-h115">M2-Q44 (V2-D5.2)</h3>

<p id="sec-bank-mocks-p519" data-kind="prose"><strong>Scenario.</strong> An agent's tool list includes a <code>run_sql</code> tool with full
database write access. Its task is read-only reporting.</p>

<p id="sec-bank-mocks-p520" data-kind="prose"><strong>Question.</strong> What is the risk, and what is the fix?</p>

<p id="sec-bank-mocks-p521" data-kind="prose"><strong>Options.</strong>
A) No risk. The task is read-only.
B) Excessive agency plus data exposure: the tool can write and delete
though the task never needs it. Fix: scope the tool to read-only or
remove it.
C) The risk is slow queries.</p>

<p id="sec-bank-mocks-p522" data-kind="prose">D) The fix is a bigger model.</p>

<p id="sec-bank-mocks-p523" data-kind="prose"><strong>Key.</strong> B. Decisive phrase: "full database write access... task is
read-only reporting." Why: the permission exceeds the task: least
privilege fails. Prompt injection or error can steer it to a write.
Counterfactual: A wins never when permissions exceed the task.</p>

wins for regulated or irreversible posts.</p>

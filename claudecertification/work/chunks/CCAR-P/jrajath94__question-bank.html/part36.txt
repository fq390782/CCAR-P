<h3 id="bank-mocks-h139">M3-Q01 (V2-D1.1)</h3>

<p id="sec-bank-mocks-p612" data-kind="prose"><strong>Scenario.</strong> An airline handles 20,000 baggage claims per day. About
88% are standard: tag number, flight, one photo. About 12% involve
disputed liability between carriers. One hard rule: no compensation on
an unverified tag.</p>

<p id="sec-bank-mocks-p613" data-kind="prose"><strong>Question.</strong> Which design fits best?</p>

<p id="sec-bank-mocks-p614" data-kind="prose"><strong>Options.</strong>
A) One agent handles every claim with no checks.
B) Deterministic rules process the 88% standard claims. Claude drafts
the liability summary for the 12% disputed claims. A code gate blocks
any compensation until the tag check passes.
C) The most capable tier handles everything with no checks.</p>

<p id="sec-bank-mocks-p615" data-kind="prose">D) Staff review all 20,000 claims.</p>

<p id="sec-bank-mocks-p616" data-kind="prose"><strong>Key.</strong> B. Decisive phrase: "no compensation on an unverified tag."
Why: the fork matches input shape to lane and the gate enforces the
hard rule. D cannot scale to 20,000. Counterfactual: D wins at 60
claims per day with fraud risk.</p>


<h3 id="bank-mocks-h140">M3-Q02 (V2-D1.1)</h3>

<p id="sec-bank-mocks-p617" data-kind="prose"><strong>Scenario.</strong> A bank's fraud team wants an AI that "blocks bad

recurring payments. About 10% are unusual. Compliance states one rule:
no block on a transaction without a logged reason.</p>

<p id="sec-bank-mocks-p618" data-kind="prose"><strong>Question.</strong> What is the best FIRST action?</p>

<p id="sec-bank-mocks-p619" data-kind="prose"><strong>Options.</strong>
A) Build the auto-block agent this week.
B) Write the rule into the design. Deterministic rules pass the 90% low-risk flow. Claude assesses the 10% unusual flow. A code gate logs the reason before any block.</p>

<p id="sec-bank-mocks-p620" data-kind="prose">C) Benchmark tiers first.
D) Draft a prompt that forbids unexplained blocks.</p>

<p id="sec-bank-mocks-p621" data-kind="prose"><strong>Key.</strong> B. Decisive phrase: "no block on a transaction without a
logged reason." Why: the constraint filters the design before build. D
puts a compliance rule in a prompt. Counterfactual: A wins for a
sandbox demo with no real transactions.</p>

<h3 id="bank-mocks-h142">M3-Q04 (V2-D1.2), Select TWO</h3>

<p id="sec-bank-mocks-p627" data-kind="prose"><strong>Question.</strong> Which TWO are trust boundaries? Select TWO.</p>

<p id="sec-bank-mocks-p628" data-kind="prose"><strong>Options.</strong>
A) Between web input and validation.
B) Between the model score and the HR system write.
C) Between validation and the model.
D) Between the log writer and storage.
E) Between two functions in one process.</p>

validation (screen it). The HR write is the side effect (authorize it
in code). The rest are internal. Counterfactual: none.</p>

crossings are not boundaries.</p>


<h3 id="bank-mocks-h143">M3-Q05 (V2-D1.3)</h3>

<h3 id="bank-mocks-h144">M3-Q06 (V2-D1.3)</h3>

same order.</p>

<p id="sec-bank-mocks-p639" data-kind="prose"><strong>Options.</strong>
A) Use an autonomous agent loop.
B) Use a deterministic workflow. The checklist is fixed. The order is fixed. The trace must be identical per contract.</p>

the workflow's exact win condition. An agent would vary the plan.
Counterfactual: A wins when the checklist itself is unknown per
contract.</p>

<h3 id="bank-mocks-h147">M3-Q09 (V2-D1.5), Select TWO</h3>

<p id="sec-bank-mocks-p651" data-kind="prose"><strong>Scenario.</strong> A software release needs: build, test, security scan, and
deploy. Build must precede test and scan. Deploy needs all three
green.</p>

<p id="sec-bank-mocks-p652" data-kind="prose"><strong>Question.</strong> Which TWO orderings are valid? Select TWO.</p>

<p id="sec-bank-mocks-p653" data-kind="prose"><strong>Options.</strong>
A) Build, then test and security scan in parallel, then deploy.
B) Build, test, scan, deploy in strict sequence.
C) Deploy first, then build.
D) Test before build.
E) Scan and deploy in parallel.</p>

<p id="sec-bank-mocks-p654" data-kind="prose"><strong>Answer.</strong> A, B</p>

<p id="sec-bank-mocks-p655" data-kind="prose"><strong>Key.</strong> A, B. Decisive phrase: &quot;Build must precede test and scan.
Deploy needs all three green.&quot; Why: both respect the dependencies.
Test and scan are independent after the build, so parallel or sequence
both work. C, D, and E break stated dependencies.</p>

<p id="sec-bank-mocks-p656" data-kind="prose">Counterfactual:
none. Dependencies decide.</p>

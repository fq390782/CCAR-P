# ⚠️ 공식 문서 검증 — 공통 지시

개념서 `output/Know(CCAR-F&P)/` 장 md에 있는 ⚠️ 표시(문항 해설이 공식 문서와 어긋나 보인다는 메모)를 공식 문서로 확인한다. **md 파일은 직접 고치지 않는다.** 결과는 fix JSON 하나로만 낸다.

## 공식 문서 (기억으로 판단하지 않는다. 매번 새로 읽는다)
- Claude API·플랫폼: https://platform.claude.com/llms.txt (목차) → 해당 페이지 `.md`
- Claude Code·Agent SDK: https://code.claude.com/docs/llms.txt
- 목차에서 페이지를 찾아 curl(`curl -sL -m 60 <url>`) 또는 WebFetch로 읽는다. 받은 파일은 scratchpad의 자기 전용 하위 폴더에만 둔다(프로젝트 폴더에 저장 금지).

## 각 ⚠️ 처리 규칙
1. **문서가 행 내용(해설)과 일치** → ⚠️와 그 이유 문구를 지운다. 행의 나머지 내용은 그대로.
2. **문서가 행 내용과 어긋남** → 행 내용(시험 해설)은 지우지 않는다. ⚠️ 이유를 "공식 문서: <문서가 말하는 사실 한 줄>" 형태로 구체화한다.
3. **문서에서 확인 불가**(문서에 없음, 시점 의존 가격 등) → ⚠️ 유지. 이유 끝에 "(공식 문서 미확인)"을 붙인다.
- 모든 문구는 한국어, 기술 용어는 영어. 표 셀은 한 줄 40자, 3줄 이내(`<br>`로 줄바꿈)를 지킨다. 근거 `<sub>` 줄과 id는 건드리지 않는다.

## 출력: `work/knowbook/verify/fix_{장번호}.json` (장마다 하나)
```
{"add": {}, "rep": [["md 안에서 정확히 1번 나오는 옛 문자열", "새 문자열"], ...]}
```
- 옛 문자열은 ⚠️가 든 부분만 짧게 잡되, md 안에서 정확히 1번 나오게 한다. python3 -I로 횟수를 확인한다.
- 그 장의 모든 ⚠️를 빠짐없이 처리한다(규칙 3이면 rep로 "(공식 문서 미확인)" 추가).
- 같은 장 파일을 다른 agent가 고치지 않으니 충돌은 없다.
